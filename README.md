# Yekta Hamrah

اپلیکیشن تشخیص و تست سخت‌افزار گوشی‌های اندرویدی.

## نسخه 1.0
- داشبورد فارسی
- شناسایی مدل و نسخه Android
- تست تاچ و ثبت لمس‌های مشکوک
- تست نمایشگر و رنگ‌ها
- تست اسپیکر
- تست ویبره
- فهرست سنسورها
- اطلاعات پایه باتری
- مشخصات سخت‌افزار
- صفحه گزارش اولیه

## نکته مهم
تشخیص Ghost Touch در این نسخه یک غربالگری نرم‌افزاری است و نباید به‌عنوان تشخیص قطعی خرابی سخت‌افزار تلقی شود.

## Build
پروژه با Android Gradle Plugin و Gradle Wrapper استاندارد قابل اتصال به GitHub Actions است.
برای شروع در Android Studio:
1. پوشه YektaHamrah را باز کنید.
2. Gradle Sync را اجرا کنید.
3. Run را بزنید.

## Roadmap
- تست دوربین و فلش
- تست میکروفون با ضبط/پخش
- تست proximity/light/accelerometer/gyroscope/magnetometer
- تست شبکه و Bluetooth
- تست USB/شارژ

- تولید PDF
- تاریخچه تست‌ها
- حالت تعمیرکار و گزارش مشتری
